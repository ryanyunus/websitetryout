Dokumen Persyaratan Integrasi Payment Gateway

Penjelasan Detail & Tangkapan Layar (Screenshots)

1. Halaman Utama & Katalog Produk (Akses Website)

Pengguna mengunjungi halaman utama website untuk melihat daftar paket Tryout yang tersedia (baik yang Gratis maupun Premium).

[Tangkapan Layar: Halaman Utama / Daftar Tryout]
Simpan screenshot halaman utama Anda dengan nama '1_homepage.png' di dalam folder 'screens'

2. Halaman Login / Pendaftaran Akun

Ketika pengguna ingin membeli paket tetapi belum masuk ke sistem, sistem akan mengarahkan pengguna ke halaman Login / Register untuk masuk atau membuat akun.

[Tangkapan Layar: Halaman Login atau Register]
Simpan screenshot halaman login Anda dengan nama '2_login.png' di dalam folder 'screens'

3. Halaman Detail Tryout (Pemilihan Paket)

Pengguna melihat detail paket tryout premium yang dipilih (berisi jumlah soal, durasi pengerjaan, dan tombol inisiasi pembelian).

[Tangkapan Layar: Halaman Detail Tryout]
Simpan screenshot halaman detail tryout Anda dengan nama '3_checkout.png' di dalam folder 'screens'

4. Halaman Checkout (Informasi Detail & Ringkasan Pesanan)

Pengguna melihat ringkasan pesanan, harga paket yang harus dibayar, serta tombol "Bayar Sekarang" untuk menginisiasi proses pembayaran di Payment Gateway.

[Tangkapan Layar: Halaman Checkout / Order Summary]
Simpan screenshot halaman checkout Anda dengan nama '4_payment_page.png' di dalam folder 'screens'

5. Halaman Payment Gateway (Pemilihan Metode Pembayaran)

Pengguna diarahkan ke halaman Payment Gateway terintegrasi untuk memilih metode pembayaran (Transfer Bank, E-Wallet, QRIS, dll.) dan menyelesaikan pembayaran.

[Tangkapan Layar: Halaman Payment Gateway (Midtrans/Tripay/Lainnya)]
Simpan screenshot halaman payment gateway dengan nama '5_payment_gateway.png' di dalam folder 'screens'

6. Halaman Transaksi Berhasil (Success Page)

Setelah pembayaran berhasil diverifikasi oleh Payment Gateway, pengguna diarahkan kembali (redirect) ke halaman website yang menampilkan pesan bahwa transaksi telah berhasil.

[Tangkapan Layar: Halaman Transaksi Berhasil]
Simpan screenshot halaman transaksi berhasil dengan nama '6_payment_success.png' di dalam folder 'screens'

7. Halaman Dashboard / Riwayat Transaksi

Pengguna dapat melihat riwayat transaksinya dengan status "Lunas" (Paid) dan mendapatkan akses untuk mulai mengerjakan Tryout yang telah dibeli.

[Tangkapan Layar: Halaman Dashboard & Akses Tryout]
Simpan screenshot halaman dashboard dengan nama '7_dashboard_access.png' di dalam folder 'screens'
